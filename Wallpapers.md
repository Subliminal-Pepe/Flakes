# Wallpapers

- `Library/` — all local collections merged and sorted by theme (see [`Library/README.md`](Library/README.md)).
- `AI-Generated/` — wallpapers with verifiable AI-generation evidence (see [`AI-Generated/README.md`](AI-Generated/README.md)).
- `NixOS/` — official NixOS artwork, sorted by category (see [`NixOS/README.md`](NixOS/README.md)).

## Where the wallpapers come from

| Folder | Source |
| --- | --- |
| `Awesome_Wallpapers/` | <https://github.com/AlexandrosLiaskos/Awesome_Wallpapers> (MIT) |
| `Wallpaper-Bank/` | <https://github.com/JaKooLit/Wallpaper-Bank> |
| `NixOS/` | <https://github.com/NixOS/nixos-artwork/tree/master/wallpapers> |
| `Hyprland/`, `Caelestia/` | local folders, source not recorded |

`Awesome_Wallpapers/` and `Wallpaper-Bank/` are upstream git clones, kept pristine so
`git pull` keeps working. `Hyprland/` and `Caelestia/` are original flat folders, kept as-is.

Full details, commits and licenses: [`Library/SOURCES.md`](Library/SOURCES.md).
`Library/.sorting/manifest.tsv` records where every library file came from
(`action`, `repository`, `local_source`, `library_destination`).
